Morse Code Translator

Type text, see the Morse code, and hear it played back

Morse code (letters separated by spaces, words by “/”)
Timing follows the PARIS standard: a dot lasts 1 unit and a dash 3. The gap is 1 unit between symbols, 3 between letters and 7 between words. One unit is 1.2 / WPM seconds. Changing the speed stops playback; tone and volume apply live. Ctrl+Enter in the text box plays or stops.
